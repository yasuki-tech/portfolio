# Portfolio

Personal portfolio website built with HTML, CSS, and JavaScript.

Created automatically using [Claude Code](https://claude.ai/code) with **GitHub MCP server**.

## Tech
- Vanilla HTML / CSS / JavaScript
- Responsive design
- Scroll-driven fade-in animations
- Fixed nav with active highlight

## Deploy with GitHub Pages
Settings > Pages > Deploy from branch `main` / `/ (root)` → Save.

The site will be live at `https://yasuki-tech.github.io/portfolio/`.
